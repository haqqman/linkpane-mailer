# Linkpane Mailer SDKs

Monorepo for Linkpane SDK packages.

## Packages

- `@linkpane/mailer-post`: Submission-only SDK for Mailer forms
- `@linkpane/mailer`: Mailer CRUD SDK (stub)
- `@linkpane/newsletter`: Newsletter SDK (stub)
